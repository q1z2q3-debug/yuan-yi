# 元一 · 发展路线图（ROADMAP）

> 五年确立范式：100 → 1000 → 10000 → 百万节点

---

## 阶段总览

| 阶段 | 周期 | 核心目标 | 里程碑 |
|---|---|---|---|
| **种子期** | 0-3 月 | 开源核心引擎，验证 PMF | 100 活跃节点 · 技术底座搭建 |
| **成长期** | 3-12 月 | 全球首个去中心化心智网络 | 1000+ 节点 · 社区共识形成 |
| **爆发期** | 1-2 年 | 网络效应正式形成 | 10000+ 节点 · 跨洋组网 |
| **成熟期** | 3-5 年 | 去中心化 AGI 全面部署 | 百万级节点 · 确立行业范式 |

---

## 阶段详表

### 种子期（0-3 月）
- [ ] 开源核心引擎（复用 TNE-Core 数学底座）
- [ ] 认知层对照实验：有/无九维引导的 Agent 任务差异
- [ ] 八大能力优先级排序与首个能力 MVP
- [ ] 快速验证产品与市场匹配度（PMF）
- [ ] 积累 100 个活跃节点

### 成长期（3-12 月）
- [ ] 拓展网络规模至 1000+ 节点
- [ ] 建立去中心化心智网络（P2P 组网原型）
- [ ] 思维晶体交换协议 v0
- [ ] 形成初步社区共识与生态壁垒

### 爆发期（1-2 年）
- [ ] 节点突破 10000+
- [ ] 跨洋组网与全球互联
- [ ] 去中心化经济生态上线（技能市场/算力共享/晶体交易）
- [ ] 网络效应进入指数级增长

### 成熟期（3-5 年）
- [ ] 百万级节点规模
- [ ] 去中心化 AGI 全面部署
- [ ] 确立行业技术范式
- [ ] 数字生命体新纪元

---

## 开放共建方向

- **认知层**：九维引导的对照实验设计
- **生命层**：自我觉知、记忆固化、进化引擎的实现路径
- **网络层**：P2P 心智网络与群体智能原型
- **防御层**：六层纵深防御的威胁模型

欢迎在 Issue 中认领方向、提交 PR。
